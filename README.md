# FYPROJECT

A final year project involving building a robot_arm for shopping purposes in supermarkets

**Autonomous Shopping Robot for Retail Supermarkets** - JKUAT, BSc. Electronic and Computer
Engineering (EEC 2501), 2026/27. Supervisor: Mr. Asaph Muhia.

The robot takes an order from an online app or its touchscreen, plans the shortest route
through a scaled store, finds each product with a camera, picks it with a robotic arm and
brings the order to a collection point.
